# PLACEHOLDERS

This manuscript uses bracketed placeholders so the book can be customized before publication. Replace each placeholder consistently across all files, then rebuild with `python3 06-production/build.py`.

There are two kinds of placeholders:

1. **Customization fields** — author, publisher, tools, prices, links. These must be replaced before publishing.
2. **Template fields** — generic labels inside the worksheets and scripts (e.g. `[ITEM]`, `[STEP]`). These can stay as fill-in fields for the reader, or be replaced with example content.

## Instructions

1. Do a global find-and-replace for each customization field before formatting.
2. Decide whether template fields should remain as fill-in prompts or be replaced with example content. For a published book, keeping them as prompts is standard.
3. Check that no `[` or `]` characters remain in the final manuscript unless they are intentional template fields.
4. Update the cover wrap, EPUB metadata, and `04-marketing/` files with the same final details.
5. Rebuild all outputs after changes: `python3 06-production/build.py`.
6. Add any new placeholders to this file as the manuscript evolves.
