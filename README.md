# Soft Life Book Project

A working repository for developing a best-selling book on the **Soft Life**.

## Core Strategy (from research)

- **Soft Life** is a psychological branding hook with high commercial intent, not a standalone search term.
- **Winning formula:** `Soft Life + specific functional utility` (avoid the generic "generalist trap").
- Target readers: millennial & Gen Z women, professional women 40+, and burned-out entrepreneurs seeking time freedom, low-stress luxury, and calm wealth.
- Every title must promise a **system, tool, or outcome** — not the abstract aesthetic.

## Project Structure

| Folder | Purpose |
| --- | --- |
| `00-research/` | Keyword, market, and audience research |
| `01-positioning/` | Titles, audience, promise, series bible, and positioning |
| `02-outline/` | Book outline and chapter summaries |
| `03-manuscript/` | Per-book manuscripts, organized by chapter (`_template/` = skeleton for new books) |
| `04-marketing/` | Launch plan, sales copy, metadata, affiliate resource plan, and stack page copy |
| `05-assets/covers/` | Book cover art (one folder per book; `_template/` spec, `_source/` raw masters) |
| `06-production/` | Series build engine: `build.py <book-id>` + `books/<book-id>.toml` configs; outputs in `06-production/dist/<book-id>/`; review site at `dist/index.html` |
| `07-audiobook/` | AI audiobook pipeline: narration scripts (`build_narration_script.py <book-id>`), voice spec, audio generation (`generate_audio.py`), mastering (`master.py`); **Book 1 produced — 3.81 h, all ACX PASS** |
| `08-app/` | **Soft Life PWA** (`soft.gabochie.com`): local dev API (`server/api.py` → localhost:8100) + installable web app — onboarding funnel, member dashboard, 90-day task engine, read-aloud library, affiliate system. MVP built & locally verified; production backend = Supabase |
