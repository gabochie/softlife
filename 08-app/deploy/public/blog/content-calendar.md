# The Soft Life Journal — 90-Day Content Calendar

**Goal:** Grow from 5 blog posts to ~31 posts (2×/week × 13 weeks) while ranking for long-tail keywords in the calm-business / premium-offer / 15-hour-week niche.  
**Owner:** Deon ChristoLove (sole writer / publisher)  
**Publish cadence:** Tuesdays and Thursdays  
**Format:** ~1,000–1,400 words, FAQ section, Article + FAQPage JSON-LD, OG image, canonical URL, internal link to at least one product/tool/chapter  
**Primary conversion:** Free app signup (`/#/signup`) → Chapter 1 audio → Complete bundle

## SEO / LLMO / AEO checklist (every post)

- [ ] Frontmatter: title, description, date, updated, author, category, tags, canonical
- [ ] `<title>` under 60 chars, includes primary keyword
- [ ] Meta description under 160 chars, includes primary keyword + CTA hint
- [ ] `Article` JSON-LD with `datePublished`, `dateModified`, `author`, `publisher`, `wordCount`, `timeRequired`
- [ ] `BreadcrumbList` JSON-LD (Home > Blog > Post)
- [ ] `FAQPage` JSON-LD with 3–5 questions from the post
- [ ] OG image (1200×630), Twitter card, canonical URL, `max-image-preview:large`
- [ ] `llms.txt` entry added (new post + description)
- [ ] RSS / Atom / JSON feed regenerated
- [ ] Internal link to at least one product/tool/chapter
- [ ] H1 matches `<title>` closely; H2s include secondary keywords
- [ ] First paragraph contains primary keyword naturally
- [ ] Readable without JavaScript (static HTML blog)
